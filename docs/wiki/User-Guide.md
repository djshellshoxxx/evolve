# User Guide

The in-app manual is the Help view; the README sections "Playing it", "The score", "Field Journal and
long-term progression", "Hidden Laboratory", "Colony Morph" (using MUTAGEN as an effect) and "The Resonance Acts"
describe play. Downloads are listed in the README "Downloads" section.

Short version: you do not edit a sound. You keep a colony interesting by feeding it (the "Feeding it" section),
using the run verbs and gesture knobs, and it scores how well you do. Presets, files and the manual are covered in
"Presets, files and the manual".
